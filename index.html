About

플러스엑스에서 약 3년 6개월 동안, 백엔드와 인프라를 한 사람이 책임지는 프로젝트를 다수 수행해 왔습니다.

Django/DRF 기반 서버 개발은 물론, AWS 인프라 구축과 CI/CD, Docker 패키징, 무중단 배포까지 직접 다룹니다. 대부분의 참여 프로젝트에서 도메인 분석과 DB 스키마 설계를 주도했고, KB 자산운용 통합 개편에서는 PL(Project Leader)로서 다중 외부 데이터 소스 통합과 검색 엔진 설계를 이끌었습니다.

최근에는 자산운용 도메인의 검색·캐싱 최적화, 그리고 ComfyUI 기반 AI 이미지 생성 서비스의 전 라이프사이클(워크플로우 설계 → API 연동 → GPU 서버 배포)에 집중하고 있습니다. 새로운 도메인을 빠르게 이해하고, 제약이 많은 환경(금융권 폐쇄망·고객사 보안망)에서도 끝까지 배포·운영해 낸 경험을 강점으로 생각합니다.

What I Do

01

설계 주도 · PL 경험

도메인 분석, DB 스키마 설계, 외부 데이터 소스 통합 협의, ETL 벤더 커뮤니케이션까지 주도. KB 자산운용 통합 개편에서 PL로 프로젝트를 이끌었습니다.

02

백엔드 + 인프라 단독 수행

Django/DRF 개발과 AWS(EC2·S3·RDS·Lambda) 구축·운영, Docker 패키징, GitHub Actions CI/CD, Blue/Green 무중단 배포를 한 사람이 책임지고 진행.

03

성능 최적화

자산운용 통합검색에서 Redis 기반 시계열 데이터 캐싱 레이어를 도입해 검색 응답을 1~2초 → 0.2초 수준(약 80% 개선)으로 단축.

04

검색 엔진 설계

Elasticsearch/OpenSearch 기반 ETF/Fund 통합검색. 동의어 사전, 자동완성, 오타 교정, 검색어 추천, 실시간 구성종목 검색을 구현.

05

AI 이미지 생성 서비스

ComfyUI 워크플로우 설계부터 API 연동, GPU 서버 배포, 멀티 모델(SD 3.5 / Flux / Kontext) 적용까지 전 라이프사이클을 단독 담당.

06

레거시 전환 · 시스템 통합

Django 템플릿 API의 DRF 전환, 그룹사 데이터 통합 마이그레이션(PlusA ↔ PlusX), 결재 라인 추상화 등 대규모 구조 전환을 수행.
